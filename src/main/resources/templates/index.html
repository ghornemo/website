ABOUT THIS PROJECT

A 2017 Spring App, Revived.

Gemal's World was originally built in 2017 as a Java/Spring Boot project for exploring political social-media posts and community discussion.

In 2026, I brought the original application back to life: containerizing its legacy Java runtime and PostgreSQL database, restoring Google authentication, and replacing its obsolete Twitter integration with the modern X API v2.

The original application workflow remains intact, including live political feeds, pinned posts, comments, the store, ordering, ratings, account history and Google authentication.
